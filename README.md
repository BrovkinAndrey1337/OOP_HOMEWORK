# Проект "HOMEWORK 14_1"

Классы Product и Category

## Описаниe

Этот проект предоставляет классы для создания продуктов и категорий.

## Использование

### Создание классов

#### Класс `class Product`
Класс создания продуктов. Атрибуты экземляра класса указываются с помощью конструктора.

##### атрибуты экземпляра:
- `name`: название продукта.
- `description`: описание продукта.
- `price`: цена за единицу продукта.
- `quantity`: количество продукта.


##### Пример создания:
```python
from src.classes import Category, Product

product = Product("Пиво", "Будущее будет светлым и нефильтрованным", 22.8, 1)
print(f"{product.name}, {product.description}, {product.price}, {product.quantity}")  # Вывод: "Пиво, Будущее будет светлым и нефильтрованным, 22.8, 1"
```

#### Класс `class Category`
Класс создания категорий. Атрибуты экземляра класса указываются с помощью конструктора. 

##### атрибуты класса:
- `total_categories`: количество категорий.
- `total_products`: количество продуктов в категории.

##### атрибуты экземпляра:
- `name`: название продукта.
- `description`: описание продукта.
- `products`: список продуктов класса Product


##### Пример создания:
```python
from src.classes import Category, Product

product = Product("Пиво", "Будущее будет светлым и нефильтрованным", 22.8, 1)
category = Category("1 на выбор", "Возьми меня", [product])
category = Category("1 на выбор", "Возьми меня", [product])

print(f"{category.name}, {category.description}, {category.products[0].name}, {category.total_products}, {category.total_categories}")  # Вывод: "1 на выбор, Возьми меня, Пиво, 1, 1"
```

#### Класс `class Smartphone`
Подкласс класса Product, класс смартфонов. Атрибуты экземляра класса указываются с помощью конструктора. 

##### атрибуты экземпляра:
- `name`: название продукта.
- `description`: описание продукта.
- `price`: цена за единицу продукта.
- `quantity`: количество продукта.
- `efficiency`: эффективность,

#### Класс `class LawnGrass`

##### атрибуты экземпляра:
